# Contributing

This repository is a mirror of the developer kit of Library of Alexandria. The clients, the command line, the bridge and the tool files are generated or kept in step with the service, so a change is made there and copied here.

Issues are welcome: a wrong answer of a tool, a missing quick-start for a host, a client that fails on your platform. Please say which program you use and the exact request; never paste a key or a token into an issue.

The clients have no dependencies and no build step. Run the tests with `node --test tests/*.test.mjs` and `python3 tests/test_python.py`.
