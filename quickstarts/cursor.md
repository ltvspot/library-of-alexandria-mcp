# Cursor

Add the library to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` (one project). No key is needed.

```json
{
  "mcpServers": {
    "library-of-alexandria": {
      "url": "https://mcp.libraryofalexandria.com/mcp"
    }
  }
}
```

Open **Cursor Settings > MCP** to see the eight tools and switch them on.
