# VS Code (GitHub Copilot)

1. Open the Command Palette and run **MCP: Add Server**.
2. Choose **HTTP (HTTP or Server-Sent Events)** and enter `https://mcp.libraryofalexandria.com/mcp`.
3. Enter the server ID `library-of-alexandria`.
4. Choose where to keep it (for one workspace or for you), then start the server from the MCP list.

The library needs no sign-in. In Copilot's chat (agent mode) the eight tools appear in the tools picker.
